Features

Hardware and software built for walking accessibility

EdgeSense combines simple sensing hardware with a live dashboard and safety-action tools to support safer movement.

Hardware

Physical system features

◢

Ultrasonic Sensor

Detects drop-offs such as stairs, curbs, ledges, and sudden changes in ground level.

◌

Potentiometer

Acts as a visibility-risk input for caution conditions and low-visibility support.

◉

Camera

Supports incident context through monitoring or snapshot-captured safety events.

●

Lights + Buttons

Provide physical feedback and support actions like quick check-ins and help alerts.

Software

Dashboard and support features

S

Status Dashboard

Shows SAFE, WARNING, or DANGER based on live or simulated sensor input.

L

Hazard Logs

Stores recent warning and danger events with timestamps and walking-condition data.

C

Trusted Contacts

Lets the user save a contact for quick check-ins and emergency support actions.

!

Safety Actions

Supports check-ins, help alerts, and an emergency alert preview panel.
