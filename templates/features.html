Features

Hardware and software built for walking accessibility

EdgeSense combines simple sensing hardware with a live dashboard and safety-action tools to support safer movement.

Hardware

Physical system features

◢

Ultrasonic Sensor

Continuously measures ground distance to detect drop-offs like stairs, curbs, and ledges—independent of lighting conditions.

●

Accessibility Button

Supports quick check-ins and emergency alerts, giving users direct control over safety actions.

◉

Camera

Provides environmental context during warnings or emergency events through monitoring or snapshot capture.

☼

Day + Night Reliability

Because the system relies on distance sensing rather than vision, it remains effective in both bright and low-light spaces.

Software

Dashboard and support features

S

Mobility Status Dashboard

Shows SAFE, WARNING, or DANGER states based on live or simulated sensor input.

L

Hazard Logs

Stores recent warning and danger events with timestamps, hazard details, and mobility guidance.

C

Trusted Contacts

Lets the user save a trusted contact using either an email address or phone number.

!

Safety Actions

Supports check-ins, emergency alerts, and a live alert preview panel for demos and real-world workflows.
